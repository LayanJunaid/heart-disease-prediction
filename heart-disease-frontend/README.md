# ❤️ Heart Disease Prediction System

An AI-powered web application designed to predict the possibility of heart disease using machine learning techniques and the UCI Heart Disease Dataset.

The system allows users to enter medical-related features and receive a prediction result with a probability percentage indicating potential heart disease risk.

---

# 📌 Project Overview

Heart disease is one of the leading causes of death worldwide. Early prediction can help users become more aware of potential health risks and encourage earlier medical consultation.

This project combines:

- Machine Learning
- Data Analysis
- Front-End Web Development
- User-Friendly UI/UX Design

to create an accessible heart disease prediction platform.

---

# ⚠️ Important Medical Disclaimer

This system is developed for:

- Educational purposes
- Research purposes
- Preliminary risk estimation

The prediction result is generated by an AI model and may not always be 100% accurate.

This application does NOT replace professional medical diagnosis or consultation.

Users should always consult qualified healthcare professionals for accurate medical evaluation.

# 📊 Features Used

The prediction system uses 14 medical-related features including:

- Age
- Sex
- Chest Pain Type
- Resting Blood Pressure
- Cholesterol
- Fasting Blood Sugar
- Resting ECG
- Maximum Heart Rate
- Exercise Induced Angina
- Oldpeak
- ST Slope
- And other heart-related attributes
